# Verdant UI — отдельные компоненты

Готовая библиотека **34 самостоятельных примеров** для чистых HTML, CSS и JavaScript с дизайном **Powder Blue / Bold Bento** и темами light/dark. Без `npm` и без обязательного сборщика.

## Запуск

Откройте папку `verdant-ui-components` в VS Code и запустите Live Server, либо из папки выполните:

```bash
python -m http.server 5500
```

Затем откройте `http://localhost:5500`.

## Где какой компонент

`components/<имя>/index.html` — HTML-разметка одного компонента; `style.css` — его локальные стили; `script.js` — рабочий JavaScript. **Каждый пример имеет свою страницу**, общую навигацию и переключатель темы. Сами универсальные модули находятся в `shared/js/components/`, дизайн-токены и общие стили — `shared/css/`.

## Как перенести на конкурсный проект

1. Скопируйте папку `shared/` в публичную папку фронтенда вашего проекта.
2. Откройте подходящий `components/<имя>/index.html`, перенесите разметку нужного элемента (обычно внутри `<article class="panel component-demo">`).
3. Подключите `shared/css/style.css`, `shared/css/bento.css` и при необходимости локальный `style.css`.
4. Перенесите JS-код из `script.js`; скорректируйте пути импорта `../../shared/` относительно вашего нового расположения.
5. Измените идентификаторы элементов, названия полей/столбцов и API-адреса под задание.

## Подключение к NestJS API

`shared/js/core/api.js` — существующий API-клиент. Посмотрите его сигнатуру перед использованием. В примере `components/table/` запрос к реальному API включается, если **до запуска script.js** определить:

```html
<script>window.VERDANT_API_ENDPOINT = '/api/requests';</script>
```

В этом режиме `loadRecords()` обращается к серверу; ожидаются `[]`, `{items: []}` или `{data: []}`. Измените `cols` в `script.js` под реальные поля API. Остальные демо-компоненты работают с локальными данными; чтобы CRUD действительно сохранял записи в базе, **замените обработчики на вызовы `api.post`, `api.patch`, `api.delete` и повторную загрузку**. Пример CRUD намеренно не притворяется подключённой базой.

ВНИМАНИЕ: `DataTable` использует **клиентские** поиск/фильтры/сортировку/пагинацию по уже полученному массиву; серверную пагинацию необходимо реализовать самостоятельно.

## Ограничения

* Фоновые картинки не используются.
* Шрифт Golos Text подключается в общих CSS; без сети используется системный fallback.
* `FileUpload` выбирает файлы, но не отправляет их на сервер: для этого понадобится `FormData`.
* `login` и `register` показывают форму и её валидацию, но без реального API не авторизуют.
* Совместимость проверяется синтаксически; полный браузерный прогон зависит от вашего окружения.
